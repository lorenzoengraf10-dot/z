# Cuarentena

Juego de supervivencia de mundo abierto con zombies (exploración, caza, pesca, base en cualquier lugar, solo o cooperativo), en pixel art 2D top-down, para PC. Proyecto sin fines de lucro. Inspirado en Project Zomboid, DayZ y The Forest.

- [`docs/MASTER_PLAN.md`](docs/MASTER_PLAN.md) — plan maestro: resumen ejecutivo, checklist de sistemas, equipo, stack, presupuesto, negocio y decisiones abiertas

- [`docs/GDD.md`](docs/GDD.md) — documento de diseño (concepto, loop de juego, pilares)
- [`docs/ROADMAP.md`](docs/ROADMAP.md) — roadmap por fases, hitos y pasos inmediatos
- [`docs/WORLD_MAP.md`](docs/WORLD_MAP.md) — diseño del mapa mundial (hub + puntos de interés)

- [`docs/LEGAL_Y_PRIVACIDAD.md`](docs/LEGAL_Y_PRIVACIDAD.md) — legal, privacidad y licencias (Argentina y global)
